# Publishing and screenshot QA

Public screenshots and directory assets must be verified visually before publication.

## Required workflow
1. Render the actual shipped UI or a static preview derived from the shipped UI.
2. Capture the image.
3. Open the captured pixels and verify that the expected dashboard, labels and data are visible.
4. Reject screenshots showing localhost errors, browser chrome, blank states, loading states or stale content.
5. Only after pixel verification, reference the image from metadata, directories, launch posts or documentation.
