# Security Policy

## Supported version

OpenRetention is early-stage software. Security fixes are applied to the current `main` branch and the latest published release unless a release states otherwise.

## Reporting a vulnerability

Please do **not** open a public issue for a vulnerability that could put users, data, credentials, or infrastructure at risk.

Use GitHub's private vulnerability reporting feature on this repository when available. Include:
- affected component and version or commit
- reproduction steps or proof of concept
- expected impact
- any suggested mitigation

If private vulnerability reporting is unavailable, avoid publishing exploit details publicly until a private reporting channel is listed here.

## Scope

The public repository contains the self-hosted core. Hosted commercial infrastructure, managed secrets, private connectors, and other non-public components are outside this repository's scope.

## Disclosure

We aim to validate legitimate reports, develop a fix, and coordinate disclosure after affected users have a reasonable opportunity to update. No bounty program is promised by this policy.

## License note

OpenRetention is source-available under Business Source License 1.1 before its Change Date. Security reporting does not change the license terms.
