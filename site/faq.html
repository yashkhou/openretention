What is OpenRetention?

OpenRetention is a source-available, self-hosted customer-success operating system for B2B SaaS teams. The current release focuses on account health, churn-risk signals, revenue at risk and renewals.

Is OpenRetention open source?

Not yet. It is source-available under Business Source License 1.1. The repository states a Change Date of September 21, 2030 and a Change License of Apache License 2.0.

Can I use OpenRetention for free?

The repository's Additional Use Grant permits internal production use for up to 100 active customer accounts, subject to the full license terms. It does not permit operating the code as a competing hosted or managed service.

What does the health score use?

The current deterministic score can incorporate product usage decline, inactivity, payment state and renewal proximity. The exact implementation is visible in the repository.

Does OpenRetention replace Gainsight or ChurnZero?

OpenRetention does not claim full feature parity. It targets a narrower use case for teams that prioritize a self-hosted, inspectable health and risk workflow.

What integrations are planned?

The roadmap names Stripe, PostHog, HubSpot, Intercom or Zendesk, and Slack. These are planned unless the repository states an integration has shipped.

Need the actual implementation?

The repository contains the scoring logic, API, SQLite schema, Docker configuration and current roadmap.
