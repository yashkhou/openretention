# Code of Conduct

OpenRetention project spaces are for technical collaboration around the software, documentation, and its ecosystem.

## Expected behavior

- Be specific, respectful, and constructive.
- Critique code, documentation, and decisions rather than people.
- Assume good faith while still asking for evidence and reproducible details.
- Respect privacy, security boundaries, and confidential information.
- Keep discussions relevant to the project.

## Unacceptable behavior

Harassment, threats, discriminatory language or conduct, deliberate intimidation, publishing another person's private information, sustained personal attacks, and knowingly disruptive behavior are not acceptable.

## Enforcement

Project maintainers may edit or remove comments, issues, pull requests, or other contributions that violate these expectations, and may restrict participation when necessary.

For ordinary project concerns, use the repository's public issue tracker. For exploitable security vulnerabilities, do **not** open a public issue; follow [SECURITY.md](SECURITY.md).

This policy applies to repository discussions and other project spaces managed by the OpenRetention maintainers.
